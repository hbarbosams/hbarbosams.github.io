Política de privacidade

Este site serve para montar a lista de espera do CaixaCerto. Aqui está, em linguagem simples, o que é coletado, para quê e como você pede para apagar.

  • Coletamos só o seu e-mail, quando você se cadastra.
  • Usamos o e-mail para a lista de espera e para falar com você sobre o CaixaCerto. Não vendemos nem compartilhamos para propaganda de terceiros.
  • O site mede visitas e cliques com o Microsoft Clarity, para entender o que funciona na página.
  • Para ver, corrigir ou apagar seus dados, escreva para contato@caixacerto.app.br.

Quem cuida dos seus dados

O CaixaCerto é um projeto independente em fase de testes. O responsável pelo tratamento dos dados (o "controlador", nos termos da LGPD, Lei 13.709/2018) pode ser contatado pelo e-mail contato@caixacerto.app.br.

O que coletamos

  • E-mail: o endereço que você digita no formulário de cadastro.
  • Dados de navegação: o Microsoft Clarity registra, de forma automática, como a página é usada: cliques, rolagem, tempo na página, tipo de aparelho e navegador, região aproximada e gravações da sessão. Para isso ele usa cookies.

Não pedimos nome, CPF, telefone nem dados bancários.

Para que usamos

  • Guardar seu lugar na lista de espera e enviar o e-mail de boas-vindas.
  • Avisar quando o CaixaCerto estiver pronto para testar e convidar para a fase de testes.
  • Fazer perguntas sobre o seu trabalho para construir uma ferramenta que sirva de verdade. Responder é opcional.
  • Entender, com os dados de navegação, quais partes da página funcionam e quais precisam melhorar.

O e-mail é tratado com base no seu consentimento, dado no momento do cadastro (art. 7º, I, da LGPD). Os dados de navegação são tratados com base no legítimo interesse de melhorar o site (art. 7º, IX), sem identificar você pelo nome.

Com quem os dados são compartilhados

Só com os serviços que fazem o site funcionar, cada um com a sua própria política de privacidade:

  • Brevo: guarda a lista de e-mails e envia as mensagens.
  • Vercel: hospeda o sistema que recebe o cadastro.
  • Microsoft Clarity: mede o uso da página.
  • GitHub Pages: hospeda este site.

Esses serviços podem guardar dados em servidores fora do Brasil, como na União Europeia e nos Estados Unidos.

Por quanto tempo

Seu e-mail fica na lista enquanto o projeto estiver ativo ou até você pedir para sair. Se o CaixaCerto for encerrado, a lista é apagada. Os dados de navegação ficam no Clarity pelo prazo definido pela Microsoft.

Seus direitos

Pela LGPD (art. 18), você pode pedir a qualquer momento:

  • confirmação de que temos dados seus e uma cópia deles;
  • correção de dados errados;
  • exclusão do seu e-mail da lista;
  • revogação do consentimento;
  • informação sobre com quem os dados foram compartilhados.

Basta escrever para contato@caixacerto.app.br. Se não ficar satisfeito com a resposta, você pode recorrer à Autoridade Nacional de Proteção de Dados (ANPD).

Para bloquear os cookies de medição, use as configurações de privacidade do seu navegador. O cadastro continua funcionando.
